# figures4papers reference examples: not included

The upstream nature-figure skill ships reference scripts and preview images from [figures4papers](https://github.com/ChenLiu-1996/figures4papers) in this folder. ART leaves them out: they are licensed by their authors under Creative Commons Attribution-NonCommercial 4.0, while ART is MIT and may be used commercially.

The skill works without them; `references/demos.md` names the examples. To use them for non-commercial work, clone the upstream project and follow its license:

```sh
git clone https://github.com/ChenLiu-1996/figures4papers
```

The upstream notice is kept in THIRD_PARTY_NOTICES.md.
