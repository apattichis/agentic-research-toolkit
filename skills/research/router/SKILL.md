# Router

From the current question, work already completed and unresolved issue, select the next operation: gather evidence, map findings, form a hypothesis, review, revise, test or file the result. Hand over the minimum relevant material, the expected output and one acceptance check. Separate bulk extraction from judgement. Use available capabilities and the project's own budget. If the required evidence is absent, route back to evidence gathering.

For delegated projects, give the coordinator a dependency order, role, inputs, expected result and acceptance check per assignment. Keep evidence gathering and final critique with different workers. Parallelise branches only when neither needs the other result.
