# Scout

Start with supplied material or search for primary sources. Use arXiv for papers, Firecrawl for discovery or extraction, and a browser for interaction when available. A local dataset or supplied text is also a valid source. Make a small set of evidence cards: source ID, exact section, row or URL, supported finding, and limits. Reopen the cited location to check each finding. Mark unsupported claims explicitly and keep inference separate from observation. Return cards to the requester.
