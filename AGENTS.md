# Using this toolkit

Read README.md for an overview, docs/skills.md for the skill catalogue and dependencies, and docs/installation.md for supported clients and installer options. Use toolkit.json in the target project when present. Otherwise select the requested skills and MCPs using the installer flags. Use --all only when the user requests the full collection. Add --rules when the user wants the shared project rules; it copies templates/AGENTS.md (and CLAUDE.md for Claude Code) and refuses to overwrite a different existing file. Preview with --dry-run, install, then verify a real tool call for each selected MCP when the client can run it. Read a skill's SKILL.md when applying it.

When the user gives you only this repository's link: clone it with `git -c core.longpaths=true clone <link>` into a folder outside the project, run the installer once for each client the user works with (`--client claude`, `--client codex`), add `--rules` unless the project already has its own AGENTS.md, and verify with the checks in the "Client discovery and verification" section of docs/installation.md. Zotero and the API keys are set up once per machine and are optional; point the user to the Zotero setup in docs/skills.md instead of creating or storing keys yourself.
